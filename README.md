# Craps Game

A simple Craps dice game implemented in Python.

## Description

This project recreates the basic rules of the Craps game using Python.

The program rolls two dice and determines whether the player wins or loses according to the game rules.

## Game Rules

- If the first roll is **7 or 11**, the player wins.
- If the first roll is **2, 3, or 12**, the player loses.
- If the first roll is **4, 5, 6, 8, 9, or 10**, that number becomes the goal number.
- The player continues rolling the dice until:
  - The goal number is rolled again → **You win**
  - A 7 is rolled before the goal number → **You lose**
